# HamzAVPN

Telegram-бот, личный кабинет и Mini App для управления подпиской на защищённое соединение. Основная касса — Platega, управление подписками — Remnawave, база — PostgreSQL.

## Настройка

1. Скопируйте `env.dist` в `.env` и заполните поля локально.
2. Создайте отдельного бота в BotFather; заполните `BOT_TOKEN`, `TG_BOT_USERNAME` и `ADMINS`. Для личных тикетов задайте служебный форум через `SUPPORT_CHAT_ID`; пользователи общаются с ботом, ссылка на служебную группу им не требуется.
3. Задайте собственные `DOMAIN`, `REMNAWAVE_SUB_HOST` и параметры Remnawave. Для Mini App настройте приложение в BotFather; `UI_MODE=tma` включает Mini App, `bot` — обычное меню. Mini App доступен на `/tma/` основного домена.
4. Установите доверенный TLS-сертификат для `DOMAIN`. В `CERT_DIR` укажите каталог с `fullchain.pem` и `privkey.pem`. При использовании симлинков их цели должны находиться внутри смонтированного каталога. После обновления сертификатов перечитайте nginx: `docker compose exec nginx nginx -s reload`.
5. Сгенерируйте отдельный `SECRET_KEY`, заполните пароль новой базы и SMTP-параметры.
   SMTP требуется только для регистрации и восстановления доступа по email; без него публичные страницы и бот работают.
6. Получите данные Platega в её личном кабинете и заполните `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`.
7. Запустите `./refresh.sh`. Скрипт создаёт базу, применяет схему, запускает бот и сайт, проверяет nginx и запускает HTTPS на стандартном порту **443**. Порт 80 используется для перенаправления на HTTPS и проверки сертификатов. Порт 443 должен быть свободен.
8. В Platega задайте Callback URL: `https://<DOMAIN>/platega`. Оставьте `PLATEGA_REVIEW_MODE=True` на время согласования; после регистрации кассы переключите в `False` и пересоздайте бот и сайт.

`.env`, сертификаты, дампы, история Git и эксплуатационные записи исходного проекта в копию не включены. Контейнеры, сеть и том PostgreSQL имеют отдельное имя проекта `hamzavpn`.

## Тарифы и документы

Действующие цены берутся из таблицы тарифов: один каталог для бота, сайта и Mini App. Срок, сумма в рублях, квота и число устройств видны до оплаты. Администратор управляет ими в боте. Дополнительные устройства рассчитываются на сервере; скидка по промокоду не изменяет их стоимость.

Публичные страницы без входа: `/privacy`, `/terms`, `/support`, `/tariffs`. В меню бота доступны документы, тарифы и личная поддержка. Политика и соглашение датированы 03.10.2026. Если каталог пуст, сначала настройте тарифы; цены не подставляются автоматически.

Для сохранения текущего каталога используйте [инструкцию переноса тарифов](docs/tariffs.md). Пользователи, платежи и персональные данные этим инструментом не переносятся.

## Обновление и проверка

```bash
./refresh.sh
python3 -m pip install -r requirements-dev.txt
python3 -m pytest -q
python3 -m compileall -q .
docker compose logs --tail=100 vpn_bot vpn_site nginx
```

Для разработки с настроенной локальной базой: `python3 -m bot` (`USE_WEBHOOK=False`) и `uvicorn webapp.main:app --reload`. В обоих режимах callback Platega принимает бот на внутреннем порту 8081; наружу его проксирует nginx.

Инструкции: [развёртывание и HTTPS](docs/deploy.md), [интеграция Platega](docs/platega.md), [установка Remnawave](docs/remnawave.md), [перенос тарифов](docs/tariffs.md), [оформление](docs/branding.md).
