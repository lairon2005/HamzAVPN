# Telegram-бот HamzAVPN

Сценарии находятся в handlers/, бизнес-логика — services/, клавиатуры — keyboards/. Используйте общий каталог тарифов и встроенную личную поддержку. Документы доступны из постоянного меню. Платежи создавайте через общий клиент Platega; данные подписки выдавайте после проверенного callback или сверки API. Параметры берите из config.py, секреты не добавляйте в исходники и инструкции.
