# Инструкции для работы с HamzAVPN

Общайся с пользователем на русском языке.

- Архитектура: обработчик → сервис → репозиторий → PostgreSQL. Telegram — aiogram, сайт — FastAPI/Jinja2, панель подписок — Remnawave.
- Основная касса — Platega. При обработке платежей проверяй авторизацию callback, сумму, валюту, статус через API и идемпотентность выдачи.
- Цены и сроки бери из активного каталога тарифов. Не добавляй вымышленные цены или контакты.
- Публичные документы и личная поддержка должны быть доступны пользователю из бота и сайта.
- Палитра чёрно-белая. Название проекта — HamzAVPN; логотип находится в `webapp/static/img/hamzavpn-logo.png`.
- Публичный HTTPS использует порт 443. Внутренний сервер callback слушает 8081.
- В документацию включай инструкции; реальные адреса инфраструктуры, реквизиты, идентификаторы пользователей и секреты туда не записывай.
- Проверки: `python3 -m pytest -q`, компиляция Python, синтаксис JS, рендер изменённых Jinja-шаблонов.
- Инструкции запуска и настройки находятся в README.md и docs/.
