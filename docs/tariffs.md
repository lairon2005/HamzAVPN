# Перенос текущих тарифов

Цены и сроки хранятся в PostgreSQL. Исходный каталог можно перенести без аккаунтов, платежей и данных инфраструктуры. Не подставляйте ориентировочные цены вместо актуальных.

1. В каталоге HamzAVPN экспортируйте тарифы из запущенной базы исходного проекта. `python3 -` исполняет переданный инструмент внутри его контейнера; файл исходного проекта не изменяется:

```bash
docker compose --project-directory ../telegram-vpn-bot --env-file ../telegram-vpn-bot/.env -f ../telegram-vpn-bot/docker-compose.yml exec -T vpn_bot python3 - export - < scripts/tariffs_catalog.py > data/tariffs.json
```

2. Проверьте `data/tariffs.json`: он должен содержать только тарифы и их цены, сроки, квоты, флаги активности и цены Stars. Если экспорт не выполнен, не импортируйте пустой или повреждённый файл.
3. Настройте новую базу HamzAVPN и запустите сервисы. Импорт разрешён только в пустой каталог:

```bash
docker compose exec -T vpn_bot python3 scripts/tariffs_catalog.py import - < data/tariffs.json
```

4. Откройте публичную страницу `/tariffs`, меню тарифов бота и Mini App. Сверьте цены, сроки, число устройств и квоты. Проверьте одну оплату по действующему тарифу.

Повторный импорт в непустой каталог останавливается без изменения цен. Дальнейшие изменения выполняйте через админку бота. Настройки стоимости дополнительных устройств находятся в отдельной таблице настроек и при необходимости задаются в админке; каталог их не переносит.
